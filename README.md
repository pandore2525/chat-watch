# Chat Watch

Расширение для Google Chrome, которое помогает отслеживать сообщения в чатах Twitch, сохранять найденные сообщения и подготовить текст жалобы. Жалобы не отправляются автоматически.

Всё необходимое для установки находится в одном архиве: [Chat-Watch-4.2.1-GitHub-bundle.zip](https://github.com/pandore2525/chat-watch/blob/main/Chat-Watch-4.2.1-GitHub-bundle.zip).

## Установка расширения

1. Скачайте ZIP-файл из раздела **Releases** на GitHub.
2. Распакуйте архив в удобную папку.
3. Откройте в Chrome:

   ```text
   chrome://extensions
   ```

4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку `twitch-chat-helper` — в ней должен находиться файл `manifest.json`.

Расширение требует Google Chrome версии 116 или новее.

## Использование

1. Откройте нужный канал Twitch.
2. Нажмите значок **Chat Watch** в панели расширений.
3. В разделе **Мониторинг** добавьте логин канала.
4. Расширение откроет чат канала в фоновой вкладке и начнёт мониторинг.
5. Добавьте остальные нужные каналы тем же способом. Поддерживается до 20 каналов.

В окне расширения доступны разделы:

- **Мониторинг** — список каналов, состояние подключения и статистика;
- **История** — найденные сообщения и статистика по каналам;
- **Настройки** — звуковой сигнал, громкость и системные уведомления;
- **Публикация** — появляется после подготовки текста жалобы.

Для найденного сообщения можно нажать **Подготовить текст**. Перед копированием и открытием жалобы появится окно подтверждения. Проверьте автора, категорию и контекст: расширение не отправляет жалобу автоматически.

Если сообщение найдено только через Chatterino+, расширение покажет предупреждение: Twitch может не увидеть исходное сообщение в форме жалобы.

## Плагин Chatterino+ `chat_watch`

Для второго источника сообщений нужен Lua-плагин `chat_watch`. Он уже находится в том же архиве `Chat-Watch-4.2.1-GitHub-bundle.zip`, в папке `chat_watch`.

1. Скачайте единый архив из [репозитория GitHub](https://github.com/pandore2525/chat-watch/blob/main/Chat-Watch-4.2.1-GitHub-bundle.zip).
2. Распакуйте его и скопируйте папку `chat_watch` в каталог Lua-плагинов Chatterino+:

```text
C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Roaming\Chatterino by Rish\Plugins
```
3. Откройте настройки Chatterino+ → **Плагины**, найдите `chat_watch` и нажмите **Включить**.
4. Перезапустите Chatterino+ или перезагрузите плагины.
5. В открытом Twitch-чате выполните `/cwadd`, чтобы добавить текущий канал.
6. Выполните `/cwinfo`, чтобы проверить состояние. Для удаления текущего канала используется `/cwremove`.

Плагин работает локально и не отправляет сообщения в сеть. Пользовательские `channels.txt` и `feed.json` создаются локально и не входят в публичный архив.

## Установка моста Chatterino+

Мост нужен только для дополнительного источника сообщений из Chatterino+. Основной мониторинг Twitch работает без него.

Требования:

- Windows;
- установленный Chatterino+;
- работающий плагин `chat_watch`.

### Установка

1. Установите расширение и откройте его popup.
2. Нажмите **Скопировать ID расширения**.
3. Откройте папку `windows-bridge` из архива.
4. Запустите `INSTALL.cmd`.
5. Вставьте скопированный ID расширения и завершите установку.
6. В popup расширения нажмите **Подключить мост**.
7. В Chatterino+ добавьте нужные каналы через `/cwadd`.
8. Для проверки состояния используйте `/cwinfo`.

Те же каналы нужно добавить и в Chat Watch. Мост работает только с указанным ID расширения.

Если мост уже был установлен ранее и ID расширения не изменился, повторная установка не требуется.

### Удаление моста

Для удаления используйте `windows-bridge/UNINSTALL.cmd`. Удаление моста не удаляет историю расширения и настройки браузера.

## Обновление

Чтобы сохранить историю и настройки:

1. Не удаляйте расширение из Chrome.
2. Скачайте новый релиз и распакуйте его.
3. Скопируйте **содержимое** новой папки `twitch-chat-helper` поверх старой папки расширения.
4. Откройте `chrome://extensions` и нажмите **Обновить**.
5. Обновите открытые вкладки Twitch.

Не устанавливайте новую копию рядом со старой: при изменении ID история может не перенестись, а мост Chatterino+ потребуется настроить заново.

## Хранение данных и ограничения

История, настройки, список каналов и черновик хранятся локально в браузере через `chrome.storage.local`. При удалении расширения данные могут быть удалены браузером.

Расширение не гарантирует обнаружение сообщений при временном сбое Twitch или Chatterino+. Открытие формы жалобы зависит от текущего интерфейса Twitch. Если исходное сообщение не найдено, может открыться профиль автора.

Лицензия шрифта Handjet находится в файле `twitch-chat-helper/fonts/OFL.txt`.
